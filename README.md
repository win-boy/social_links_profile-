### What I Learned

This project helped strengthen my understanding of building simple and responsive user interface components with HTML and CSS.

One of the main areas I practiced was using Flexbox to center the profile card on the page:

```css
body {
  min-height: 100vh;
  display: flex;
  justify-content: center;
  align-items: center;
}
```

I also gained more experience styling interactive elements and creating visual feedback when users hover over links:

```css
.social-link:hover {
  cursor: pointer;
}
```

Through this challenge, I improved my understanding of:

- Structuring content with semantic HTML
- Centering elements with Flexbox
- Managing spacing and alignment
- Styling reusable link components
- Working with typography and colors
- Creating hover and focus states
- Building responsive layouts
